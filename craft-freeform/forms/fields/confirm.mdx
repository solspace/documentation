# Confirm<Badge type="pro" text="Pro" /><Badge type="feature" text="Improved in 5.0+" /> {#confirm}


<span id="confirm" />
A field that allows you to force a user to re-enter a matching value for another text input field, including [Password](./password.mdx#password) fields (e.g. "Confirm Email Address", "Confirm Password"). It runs through additional validation to make sure field values match. If not, it'll show an error. This field stores the data as well, in case that is important for your site's needs. The `field.type` property value is `confirm` (for conditionals).

<Photo
  img={require('@site/static/img/craft/freeform/v5/forms/fields/confirm.png')}
  alt="Confirm field type"
/>

## Settings

- Choose a target field to validate against, e.g. **Email** field.
  - Available fields must be of text input type, but don't necessarily need to be of the [Text](./text.mdx#text) field type - you can use with [Email](./email.mdx#email) fields, [Password](./password.mdx#password) special fields, [Phone](./phone.mdx#phone) fields, etc.
