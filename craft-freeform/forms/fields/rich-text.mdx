# Rich Text<Badge type="pro" text="Pro" /><Badge type="feature" text="Improved in 5.10+" /> {#rich-text}


<span id="rich-text" />
A special field type that allows you include rich text inside your form layout in the form builder. The `field.type` property value is `rich-text` (for conditionals).

You may also customize which components appear in the Rich Text editor toolbar and in what order. Only core native [TinyMCE components](https://www.tiny.cloud/docs/tinymce/latest/available-toolbar-buttons/) are supported. See the [Rich Text Field Toolbar Configuration](../../configuration/settings/form-builder.mdx) setting under the [Form Builder settings](../../configuration/settings/form-builder.mdx).

<Photo
  img={require('@site/static/img/craft/freeform/v5/forms/fields/html-rich-text.png')}
  alt="Rich Text field type"
/>

## Behavior & Limitations

- The Property Editor will load a Rich Text area for you to type into and style as necessary.
- The Layout column in the form builder will live parse your content.
