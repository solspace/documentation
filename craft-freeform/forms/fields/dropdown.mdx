# Dropdown<Badge type="feature" text="Renamed in 5.0+, Improved in 5.17+" /> {#dropdown}


<span id="dropdown" />
A select dropdown menu field. The `field.type` property value is `dropdown` (for conditionals).

<Photo
  img={require('@site/static/img/craft/freeform/v5/forms/fields/dropdown.jpg')}
  alt="Dropdown field type"
/>

## Settings

- Can specify labels (with values assumed) or labels and values (that differ).
  - To make the first option empty, use **labels and values** approach with the first option having something like **Please select...** for the label, and leave option blank.
- Supports `<optgroup>`'s. To use this, enable the toggle under the **Optgroup** column for the applicable row.<Badge type="feature" text="New in 5.13+" />
- Can be automatically populated with select [Craft Elements or Pre-defined list options](./populating-options.mdx#populating-field-options).
- Can be used as a [User Select](../email-notifications/index.mdx#user-select) email notification.
- **Enable Search**<Badge type="feature" text="New in 5.17+" />
  - Lets visitors filter the available options by typing, making longer lists easier to navigate. Disabled by default.

## Styling & Customization

### Customize Searchable Dropdowns<Badge type="feature" text="New in 5.17+" /> {#customize-searchable-dropdowns}

When **Enable Search** is enabled, Freeform enhances the Dropdown with a searchable control. Its appearance is derived from the original select's styles.

### Appearance {#appearance}

Wrap the field in a container such as `.my-dropdown`, then customize the generated control:

```css showLineNumbers
.my-dropdown .ff-searchable {
  --ff-searchable-bg: #fff !important;
  --ff-searchable-menu-bg: #fff !important;
  --ff-searchable-color: #1f2937 !important;
  --ff-searchable-border: #d1d5db !important;
  --ff-searchable-radius: 6px !important;
}

.my-dropdown .ff-searchable__list {
  max-height: 12rem;
}

.my-dropdown .ff-searchable__option:not([aria-disabled="true"]):hover,
.my-dropdown .ff-searchable__option[data-active] {
  background: #4f46e5;
  color: #fff;
}
```

The CSS properties require `!important` because Freeform applies automatically derived theme values inline.

### Search labels {#search-labels}

Default labels are translatable. Manually rendered selects can provide custom wording through the JSON configuration in `data-freeform-searchable`:

```html showLineNumbers
<div class="my-dropdown">
  <select
    name="country"
    data-freeform-searchable='{
      "enabled": true,
      "placeholder": "Search countries...",
      "noResults": "No matching countries.",
      "toggleLabel": "Show countries",
      "resultsLabel": "{count} countries available."
    }'
  >
    <option value="">Select a country</option>
    <option value="ca">Canada</option>
    <option value="us">United States</option>
  </select>
</div>
```

Keep `{count}` in the results message. The original select remains responsible for submitted values. Custom templates must load Freeform's JavaScript and searchable-select styles.

## Templating

<div className="field-properties">

| Property | Description |
|---|---|
| `field.enableSearch` | Whether **Enable Search** is enabled for the field. |
| `field.searchableConfig` | The search configuration, including its enabled state and translated interface labels. |

</div>

The `searchableConfig` object contains:

| Key | Description |
|---|---|
| `enabled` | Whether the searchable control is enabled. |
| `placeholder` | Placeholder text for the search input. |
| `noResults` | Message displayed when no options match. |
| `toggleLabel` | Accessible label for the button that opens the options. |
| `resultsLabel` | Results announcement containing the `{count}` placeholder. |
| `removeLabel` | Label for removing a selected option in Multiple Select fields, containing the `{label}` placeholder. |

Use `field.render()` or `field.renderInput()` to generate the `data-freeform-searchable` configuration automatically when search is enabled.

The underlying select remains responsible for submitted values. When manually rendering a Multiple Select field, preserve its `multiple` attribute and array-style input name.
