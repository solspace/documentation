# Image<Badge type="pro" text="Pro" /><Badge type="feature" text="New in 5.13+" /> {#image}


<span id="image" />
A field that allows you to select or upload image assets into form layouts.

## Settings

The following additional settings are available to this field type:

- **Image Transform**
  - Choose an Asset image transform to apply to any images added to the image.
- **Srcset Sizes**
  - Enter a comma separated list of image size numbers for `srcset` attribute generation, e.g. `480, 768, 1024`
- **Image**
  - Select an image asset for this field.

### Customize Image Display<Badge type="feature" text="New in 5.18+" />

Enable **Customize Image Display** to resize or frame the image without changing its source asset. Leave it off to retain the original display.

- **Display Width:** use 0 to fill the available width, or enter a pixel width up to 4,000. Images shrink to fit smaller screens.
- **Aspect Ratio:** Original, Landscape (16:9), Photo (4:3), Square (1:1), or Portrait (3:4).
- **Image Fit:** with a fixed ratio, choose **Crop to fill** or **Fit entire image**.
- **Crop Position:** choose the part of the image to keep in view, such as Center, Top, or Bottom right.

These display controls can be used alongside the existing asset transform and srcset settings.
