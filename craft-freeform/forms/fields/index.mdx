## Working with Fields

- [Standard Settings](./standard-settings.mdx) — labels, handles, validation, autofill, and attributes.
- [Favorite Fields](./favorite-fields.mdx) — save and reuse field configurations.
- [Populating Field Options](./populating-options.mdx) — predefined lists and Craft Element sources.
- [Field Encryption](./field-encryption.mdx) — encrypt stored submission values.
- [Custom Field Types](../../developer/field-types.mdx) — create your own field types.

## Rendering Fields

Use Freeform's render helpers to retain the markup and attributes required by each field's enabled features. See [Field Object](../../templates/objects/field.mdx), [Formatting Templates](../../templates/formatting/index.mdx), and the individual field's **Templating** section.

For React and Vue implementations, start with [Headless Forms](../../headless/index.mdx).
