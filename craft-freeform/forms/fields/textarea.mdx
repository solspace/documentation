# Textarea<Badge type="feature" text="Improved in 5.17+" /> {#textarea}


<span id="textarea" />
A multi-line text input field. The `field.type` property value is `textarea` (for conditionals).

  img={require('@site/static/img/craft/freeform/v5/forms/fields/textarea.png')}
  alt="Textarea field type"

## Settings

- Can specify the number of rows the textarea should have.
- **Auto Grow**<Badge type="feature" text="New in 5.17+" />
  - Automatically adjusts the field's height to fit its contents. Disabled by default.
- **Maximum Height**<Badge type="feature" text="New in 5.17+" />
  - Sets the maximum height in pixels before the field scrolls. Available when Auto Grow is enabled; leave blank for no limit.
- **Show Character Count**<Badge type="feature" text="New in 5.17+" />
  - Displays a live character count below the field. If a maximum length is set, the count also shows that limit. Disabled by default.

## Styling & Customization

### Customize the Character Count<Badge type="feature" text="New in 5.17+" /> {#customize-the-character-count-1}
Set the normal and over-limit colors using CSS properties:

```css
.freeform-form {
  --ff-character-count-color: #6b7280;
  --ff-character-count-error: #dc3545;
}
```

Target `.freeform-character-count` to adjust its appearance:

```css
.freeform-character-count {
  text-align: start;
  font-size: 0.8125rem;
  margin-top: 0.375rem;
}
```

The default messages `{count} characters` and `{count} / {limit} characters` are translatable. Manually rendered fields can provide custom wording through input attributes:

```html
<textarea
  name="message"
  maxlength="500"
  data-freeform-character-count
  data-character-count-message="{count} characters entered"
  data-character-count-limit-message="{count} of {limit} characters"
></textarea>
```

Keep `{count}` and `{limit}` as placeholders; Freeform replaces them with the current values. The over-limit color applies when the count **exceeds** the maximum, rather than when it reaches it.

## Templating

<div className="field-properties">

| Property | Description |
|---|---|
| `field.browserAutofill` | The configured HTML `autocomplete` value. An empty string means use the browser default. |
| `field.showCharacterCount` | Whether the live character count is enabled. |
| `field.characterCountMessages` | An object containing the translated `count` and `limit` message formats, including their `{count}` and `{limit}` placeholders. |
| `field.autoGrow` | Whether the textarea automatically grows to fit its contents. |
| `field.autoGrowMaxHeight` | The maximum automatic height in pixels, or `null` when no limit is configured. |

</div>

Use `field.render()` or `field.renderInput()` to generate the attributes needed for character counting and automatic height adjustment.
