# Date & Time<Badge type="pro" text="Pro" /> {#date--time}


<span id="date--time" />
A complex date and/or time field. Can be used as Date only, Time only, or both. Many configuration and validation options available as well. The `field.type` property value is `datetime` (for conditionals).

## Settings

- May contain a default date value.
  - Use an English date expression such as `now`, `today`, `5 days ago`, or `2025-01-01 20:00:00`. Freeform formats the result using the configured display format and locale.
- Choose a **Date picker**: Freeform, Classic (Flatpickr), Browser, or None. See [Picker Choices](#picker-choices).
  - Freeform will automatically insert javascript in the footer/inside form (depending on settings) of the page for this fieldtype.
- Choose to have your own placeholder or have Freeform generate a placeholder based on the settings below.
- Set the date order formatting you'd like:
  - `year month day`, `month day year`, `day month year`
- Select if the year should be displayed/validated as 4 digits.
- Select if the day and month numbers should have a leading `0` for single digit values (e.g. August will display as `08` instead of `8`).
- Choose the date separator character used between each year, month, day value:
  - None, Space (` `), `/`, `-`, `.`
- Select if time and datepicker should use 24 hour clock.
- Choose the clock separator character used to separate hours and minutes:
  - None, Space (` `), `:`, `-`, `.`
- Choose if placeholder should separate AM/PM with a space (for 12hr clock).
- Select the Min and Max dates for the date picker and validation (optional). Use static dates (e.g. `2018-11-01`, `2018-11-30`) or relative date strings (e.g. `-10 days`, `+3 months`).

### Picker Choices<Badge type="feature" text="New in 5.18+" /> {#picker-choices}

| Date picker | Behavior |
| --- | --- |
| **Freeform** | Searchable month and year menus, calendar and time list, and keyboard navigation. The default for new fields. |
| **Classic** | Flatpickr, including existing Flatpickr JavaScript customization events. |
| **Browser** | Device-native `date`, `time`, or `datetime-local` controls. |
| **None** | Text input without an automatically loaded picker, for manual entry or your own JavaScript picker. |

Existing fields and saved defaults retain their configured picker when upgrading. Choose **Classic** if your template depends on Flatpickr events or instance options.

For Freeform time and combined fields, **Time interval** offers **1**, **5**, **10**, **15**, **30**, or **60 minutes**, defaulting to **30**. Visitors can also type a time between the suggestions. The picker respects the field's 12/24-hour clock and display format.

The redesigned settings show date-format previews and calendar controls while still accepting English date expressions. Minimum and maximum expressions retain their time component for combined date/time fields, such as `12 hours ago`. A date-only maximum includes the whole day.

### Date Expressions and Native Inputs<Badge type="feature" text="Improved in 5.17.3+" />

Keep **Initial value**, **Minimum date**, and **Maximum date** expressions in **English**, regardless of the control panel language. For example, enter `today` or `+3 months` even in a French or German control panel. In 5.17.3+, the builder's examples remain in English to avoid suggesting translated expressions that cannot be parsed. The displayed date and picker interface can still be localized.

With **Date picker → Browser** (or the legacy **Use native input types** setting), date fields render as `date`, time fields as `time`, and combined fields as `datetime-local`. Native date and combined inputs receive configured minimum and maximum date constraints in the browser's required format. Native **time-only** inputs omit those date constraints, so dates left over from a field's previous mode cannot block time entry.

## Behavior & Limitations

For **localization** reference:

- The _Flatpickr_ date picker will automatically localize according to the locale set for your site. Locales available are only 2-letter codes like `fr`, `de`, etc. In the event you're using a locale like `fr-CA` or `es-US`, etc, Freeform will just look at the first 2 letters and use that as the locale.
- To translate the formatting syntax error message, be sure to translate the following strings:
  - `"{value}" does not conform to "{format}" format.`
  - To translate the `{format}` rendered value to match the current locale, be sure to also translate whatever the rendered string is in the error message. For example, if you're using `fr` locale, and wish to have the default English `DD/MM/YYYY` show up as `JJ/MM/AAAA`, create a static translation for this manually.

**Dark picker theme**<Badge type="feature" text="New in 5.17.3+" /> - bundled dark formatting templates automatically use a matching dark date and time picker. For custom templates, add `data-freeform-theme="dark"` to the form or a surrounding element. See [Date Picker Events](../../developer/datepicker.mdx#dark-picker-theme) for manual dark/light overrides, CSS color customization, and JavaScript examples.

## Templating

<div className="field-properties">

| Property | Description |
|---|---|
| `field.initialValue` | The initial date or time expression for the current language. Date expressions must remain in English. |
| `field.dateTimeType` | The configured mode: `date`, `time`, or `both`. |
| `field.generatePlaceholder` | Whether the placeholder is generated from the configured format. |
| `field.dateOrder` | The date component order, such as `ymd`. |
| `field.date4DigitYear` | Whether the year uses four digits. |
| `field.dateLeadingZero` | Whether date components use leading zeroes. |
| `field.dateSeparator` | The separator between date components. |
| `field.clock24h` | Whether times use a 24-hour clock. |
| `field.clockSeparator` | The separator between hours and minutes. |
| `field.clockAMPMSeparate` | Whether a space separates the time from AM or PM. |
| `field.picker` | Picker choice: `freeform`, `flatpickr`, `browser`, or `none`. |
| `field.minuteStep` | Suggested time interval in minutes for the Freeform picker. |
| `field.useDatepicker` | Compatibility property indicating whether a JavaScript picker is enabled. |
| `field.minDate` | The minimum date expression for the current language, or `null` when unset. Date expressions must remain in English. |
| `field.maxDate` | The maximum date expression for the current language, or `null` when unset. Date expressions must remain in English. |

</div>
