# Group<Badge type="pro" text="Pro" /><Badge type="feature" text="New in 5.0+" /> {#group}


<span id="group" />
A field that contains other fields within it. To use, add a Group field into your form's layout, then add/drag other fields into that Group inside the form builder. This becomes especially powerful when using with [Conditional Rules](../conditional-rules.mdx), as you'll be able create a single rule to show/hide an entire group of fields at once.
