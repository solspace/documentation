# Calculation<Badge type="pro" text="Pro" /><Badge type="feature" text="New in 5.1+" /> {#calculation}


<span id="calculation" />
The Calculation field type lets you perform dynamic calculations based on user-input values in your forms. It also supports a wide variety of operators.

<Photo
  img={require('@site/static/img/craft/freeform/v5/forms/fields/calculation.png')}
  alt="Calculation field configuration"
/>

:::warning
For the Calculation field to work as a dynamic amount with the [Stripe Payments](../../integrations/stripe-payments.mdx) integration, the **Input Type** setting should be set to _Regular Text Input_ or _Plain Text_. If set to _Hidden_, the Calculation field should be within a multipage setup where it is on a page _before_ the page with the Stripe Payment Element field.
:::

## Settings

The following additional settings are available to this field type:

### Decimal Count<Badge type="feature" text="New in 5.6+" /> {#decimal-count}

The _Decimal Count_ setting allows you to set the maximum number of decimal places the calculated result should have. Leave blank if you don't want to limit the decimal places. If you'd like to have no decimals (whole numbers only), enter a value of `0`.

## Behavior & Limitations

### Supported Field Types

The following fields can be accessed within field calculation formulas:

- [Dropdown](./dropdown.mdx#dropdown)
- [Hidden](./hidden.mdx#hidden)
- [Invisible](./invisible.mdx#invisible)
- [Number](./number.mdx#number)
- [Opinion Scale](./opinion-scale.mdx#opinion-scale)
- [Radios](./radios.mdx#radios)
- [Rating](./rating.mdx#rating)
- [Regex](./regex.mdx#regex)
- [Text](./text.mdx#text)
- [Textarea](./textarea.mdx#textarea)

### Supported Operators

Utilizing [Symfony Expression Syntax](https://symfony.com/doc/current/reference/formats/expression_language.html), the Calculation field type empowers users to create sophisticated calculations effortlessly. From fundamental arithmetic to complex logical operations, users can employ an array of operators and functions to achieve desired outcomes.

Click on the tabs below to learn more about each operator:

<Tabs>
<TabItem value="calculation-operators-arithmetic" label="Arithmetic" default>

| Operator | Description |
| -------- | -------------- |
| `+` | Addition |
| `-` | Subtraction |
| `*` | Multiplication |
| `/` | Division |
| `sqrt()` | Square Root<Badge type="feature" text="New in 5.9.3+" /> |

<Tabs>

```

```

</TabItem>

<TabItem value="Output" label="Output">

```

```

</TabItem>
