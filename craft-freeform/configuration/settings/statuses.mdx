# Statuses

Use **Freeform → Settings → Statuses** to create and manage statuses for submissions. Configure the default status in [Form Builder settings](./form-builder.mdx#defaults-settings).

:::info
Statuses remain editable when Craft's `allowAdminChanges` setting is `false`.
:::
