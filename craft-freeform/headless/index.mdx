# Headless

Freeform supports headless website architecture for JavaScript front ends such as React, Next.js, and Vue.js.

**Recommended for new React / Next.js projects:** the official npm packages (`0.1.0-beta.x` on the `beta` tag) and the headless REST API (ships with the Freeform plugin on main). GraphQL remains available for existing integrations.

:::info Public Beta
Start with [Getting Started](./getting-started) to enable headless and install `@solspace/freeform-react`.
:::
