# Headless<Badge type="feature" text="Improved in 5.16+" />

Freeform supports headless website architecture for JavaScript front ends such as React, Next.js, Vue.js, and Nuxt.

**Official _npm_ Packages**<Badge type="feature" text="New in 5.16+" />

Freeform 5.16+ now includes official `npm` packages (`@solspace/freeform-react` or `@solspace/freeform-vue`) and a headless REST API. Start with [Getting Started](./getting-started) to enable headless and install the packages, or try the [React](https://github.com/solspace/freeform-headless-react-demo), [Vue](https://github.com/solspace/freeform-headless-vue-demo), and [Nuxt](https://github.com/solspace/freeform-headless-nuxt-demo) demos.

:::info
For projects already using Craft GraphQL, we recommend using the [headless GraphQL adapters](./graphql#headless-graphql-adapters).
:::
