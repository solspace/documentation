# daisyUI<Badge type="feature" text="New in 5.17+" />

Freeform includes sample formatting templates built to work with [daisyUI](https://daisyui.com). When using these
templates, Freeform assumes that the required daisyUI 5 styles and components are already included in your project.
While the templates may not work for all sites out of the box, they provide a solid starting point for building your own.

The following are available:

### CDN Links

**daisyUI** is typically installed via CLI, but you may find it easier to work with the CDN while developing.
Please see official [daisyUI documentation](https://daisyui.com/docs/install/) for latest versions and CDN links.

```html
<link href="https://cdn.jsdelivr.net/npm/daisyui@5.7.27" rel="stylesheet" type="text/css">
<script src="https://cdn.jsdelivr.net/npm/@tailwindcss/browser@4.3.3"></script>
```
