# Tailwind CSS<Badge type="feature" text="Improved in 5.0+" />

Freeform includes sample formatting templates built to work with [Tailwind CSS](https://tailwindcss.com). In Freeform **5.17+**, bundled **Tailwind 3** samples include compiled Tailwind CSS through Freeform's asset loading; they do not require the browser CDN. For **Tailwind 4** forms on your site, include the required Tailwind styles in your project.

The samples provide a starting point for customization. Ensure your project's Tailwind build includes any additional classes you introduce. The builder's [Preview tab](../../forms/builder/preview.mdx) and installed demo templates provide framework assets for the bundled samples automatically.

### CDN Links

These CDN examples are useful for development when your page needs Tailwind and does not already load it. Freeform 5.17+ bundled Tailwind 3 samples already include compiled CSS, so they do not need the Tailwind 3 CDN script below. For custom templates, use the asset setup appropriate to your project.
Please see official [Tailwind CSS documentation](https://tailwindcss.com/docs/installation/play-cdn) for latest versions and CDN links.

<Tabs>
  <TabItem value="cdn-tailwind-4" label="Tailwind 4" default>
    ```html
    <script src="https://cdn.jsdelivr.net/npm/@tailwindcss/browser@4"></script>
    ```
  </TabItem>
  <TabItem value="cdn-tailwind-3" label="Tailwind 3">
    ```html
    <script src="https://cdn.tailwindcss.com"></script>
    ```
  </TabItem>
</Tabs>
