# Convert Email Templates to Files

The Template Manager includes a utility to convert global database email notification templates to files. It also updates existing forms to use the new file-based templates.

<VerticalStepWrapper>
<StepMarkdown>

Create an email template directory inside Craft's site templates directory.

</StepMarkdown>
<StepMarkdown>

Open **Freeform → Settings → Template Manager** and configure the **File Directory Path** for email templates. Choose a storage type that supports files.

</StepMarkdown>
<StepMarkdown>

Use **Convert Database email templates to File email templates**.

</StepMarkdown>
<StepMarkdown>

Enable the cleanup checkbox only if you want the original database templates removed after conversion.

</StepMarkdown>
</VerticalStepWrapper>

The converted templates can still be edited in the control panel when file-template editing is enabled.

See [Template Manager](../../configuration/settings/template-manager.mdx#email-templates) for the storage and editing settings.
