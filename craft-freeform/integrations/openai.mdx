# OpenAI<Badge type="pro" text="Pro" /><Badge type="feature" text="New in 5.12+" />

This integration allows you to use [OpenAI](https://openai.com)'s AI models for processing in form submissions.

Once you enable and configure an AI integration, various AI functionality becomes available in Freeform, including the [AI field type](../forms/fields/ai.mdx#ai). Use it to provide a system prompt with instructions for how the model should process submission data (e.g., categorization, summarization, sentiment analysis, content generation). Specify the exact output format you need.

## Create Forms from PDFs and Images<Badge type="feature" text="New in 5.17+" />

Use this enabled integration with **Create with AI** to generate editable Freeform fields from a text prompt or compatible reference files. File support depends on the model configured here. See [Create Forms with AI](../forms/builder/create-with-ai.mdx) for supported files, model compatibility, and the review workflow.

## Setup Instructions

<VerticalStepWrapper>
<StepMarkdown>

### Create & get API Key from OpenAI

Visit your [account settings area](https://platform.openai.com/api-keys) on the OpenAI site to get your API key.

</StepMarkdown>
<StepMarkdown>

### Configure the Integration

- Go to the [Integrations](index.mdx#control-panel-settings) section in Freeform Settings (**Freeform** → **Integrations**).
- Find _OpenAI_ in the list of **service providers**.
- Copy and paste your API key into the integration in Freeform.

</StepMarkdown>
<StepMarkdown>

### Choosing a Model

After entering your **API Key**, Freeform loads model choices from the provider. Use the searchable **Model** dropdown to select a model, or click **Refresh models** to reload the list.

To enter a model manually, select **Other / Custom model ID** and enter its exact ID. This is also available if the model list cannot be loaded or your model is not listed. The model must be accessible to your API key and compatible with Freeform's integration.

:::info
When choosing a model, consider that AI processing can potentially hold up form submission processing for the user submitting the form, so try to choose a more light-weight model.
:::

#### Recommended Models

- ⚡ `gpt-nano` — fast + cheap
  - High-volume, simple tasks
- ⚖️ `gpt-mini` — balanced
  - Balance of speed + intelligence
- 🧠 `gpt-astra` — smartest
  - Complex reasoning, coding, agents

---

- Configure **Reasoning Effort** and **Max Tokens** as needed; see [Reasoning Effort](#reasoning-effort) below.
- Click the **Save** button.

</StepMarkdown>
<StepMarkdown>

### Authorize the Integration

- After the integration is saved, you will see an **Authorize** button appear.
- Click the **Authorize** button.
- If authorized successfully, you'll see a green _Authorized_ status at the top beside the integration name.

</StepMarkdown>
<StepMarkdown>

### Configure the Form

To use this integration on your form(s), you'll need to configure each form individually.

- Visit the form inside the form builder.
- Click on the **Integrations** tab.
- Click on **OpenAI** in the list of available integrations.
- On the right side of the page:
  - Enable the integration.

</StepMarkdown>
</VerticalStepWrapper>

## Reasoning Effort<Badge type="feature" text="New in 5.17.2+" /> {#reasoning-effort}

The integration's **Reasoning Effort** setting offers **Model default**, **Low**, **Medium**, **High**, **Extra high**, and **Maximum**. **Model default** leaves the choice to OpenAI. An explicit level requires a model that supports it; a higher setting can take longer and use more tokens.

**Max Tokens** sets the response allowance, including reasoning and generated content. Large generated forms or higher reasoning levels may need a larger allowance. If form generation reports that the response was cut short, increase this limit or generate a smaller section.

Compatible OpenAI models use [resumable background generation](../forms/builder/create-with-ai.mdx#resumable-openai-generation) for **Create with AI**. Reopen the dialog in the same browser tab to check progress and retrieve the result. This form-creation workflow is separate from processing AI fields during a visitor's submission.
