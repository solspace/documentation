# SolspaceAI<Badge type="pro" text="Pro" /><Badge type="feature" text="New in 6.0+" />

The **SolspaceAI** integration brings AI-assisted event and calendar creation into Calendar with no third-party API keys or accounts to manage. Describe what you need in plain language and Calendar will draft titles, times, recurrence rules, Additional / Excluded Dates, and even customized occurrences — then you review and save.

Built and maintained by [Solspace](https://solspace.com), SolspaceAI is a turnkey solution. Every **Calendar Pro** license includes **1,000 free credits** so you can try it risk-free. When you need more, purchase one-time credit bundles (no subscription). Credits never expire.

## What you can do

| Feature | Where | What it does |
| ------- | ----- | ------------ |
| **Create with AI** | Overview (Month / Week / Day) | Generate a new event draft from a prompt, then place it on the calendar. |
| **Update with AI** | Event editor (new or existing) | Change only what you ask for — title, times, recurrence, Additional Dates, Excluded Dates, or a customized occurrence — and leave everything else alone. |
| **Create with AI** | Calendars | Generate a new calendar (name, handle, color, description), then finish the field layout yourself. |

:::tip Update-only changes
When you use **Update with AI** on an existing event, say only what should change (for example, “exclude next Monday” or “rename to Weekly Sync”). Unrelated fields stay as they are.
:::

## Setup Instructions

<VerticalStepWrapper>
<StepMarkdown>

### Enable SolspaceAI

- Go to **Calendar → Settings → SolspaceAI**.
- Enter your **Contact Email** and public **Site URL** (for example `https://yoursite.com`).
- Click **Enable**. Enable also authorizes SolspaceAI automatically when possible.

</StepMarkdown>
<StepMarkdown>

### Authorize (if needed)

- If the status shows **Unauthorized**, click **Authorize**.
- When connected successfully, you will see a green **Authorized** status beside SolspaceAI.
- Use **Reconnect** if you change your site URL or need to refresh the connection.

</StepMarkdown>
<StepMarkdown>

### Start creating

- On **Overview**, use **Create with AI** to draft new events.
- On the **event editor**, use **Update with AI** to change an existing (or blank new) event.
- On **Calendars**, use **Create with AI** to generate a calendar, then complete the field layout.

If SolspaceAI is not connected yet, the button may read **Enable AI** and take you to the SolspaceAI settings page.

</StepMarkdown>
</VerticalStepWrapper>

## Create Events with AI

On the Overview calendar, click **Create with AI**, describe the event, then generate. Calendar opens a draft you can adjust before saving.

You can name the calendar in the prompt when you have more than one (for example, “On the Staff Meetings calendar…”). Relative phrases like “tomorrow at 9am” use your browser timezone.

## Update Events with AI

On the event editor, click **Update with AI** and describe only the change you want. This works for blank new events (after you pick a calendar with **+ New Event**) and for existing events.

### Fill a blank new event

When the calendar is already selected, you do not need to name it in the prompt.

```
Team standup every Monday at 9am for 30 minutes
```

```
Team Standup every Monday and Thursday starting next Monday for 20 times. Location "Conference Room A", description "Weekly sync."
```

```
Kickoff tomorrow at 2pm for 90 minutes. Location "Zoom". Description "Project kickoff with stakeholders."
```

```
All-day training next Thursday
```

```
Office hours every Friday 3pm–5pm for 8 weeks
```

```
Biweekly demo every other Tuesday at 11am for 45 minutes, starting next Tuesday, for 10 times
```

### Title, location, and description

Only the fields you mention should change; the schedule stays the same.

```
Rename to "Weekly Product Sync"
```

```
Change the description to "Sync on blockers and priorities."
```

```
Set location to "Building 2, Room 14"
```

```
Clear the location
```

### Move / reschedule

```
Move to next Tuesday at 3pm
```

```
Make it tomorrow at 10am
```

```
Shift the start to 9:30am and keep the same duration
```

```
Move it one week later
```

```
Make it all day next Friday
```

```
Change it from all-day to a timed event: 9am–5pm
```


### Additional Dates

Extra dates outside the recurring pattern (Additional Dates). The instance keeps the series title, location, and times unless you also customize that occurrence.

```
add an additional date 24 oct
```

```
Also on October 24
```

```
Add an extra occurrence on 2026-10-24
```

```
Add additional dates on Oct 24 and Oct 31
```

```
Also meet on the first Friday of next month
```

### Excluded Dates

Skip dates from the recurring pattern (Excluded Dates). The series rule stays the same; previous exclusions are kept.

```
exclude Oct 24
```

```
Skip Thanksgiving
```

```
Off for Christmas Day
```

```
Remove the occurrence on 25 December
```

```
Exclude next Monday from the series
```

```
Skip Oct 24 and Oct 31
```

### Customized / edited occurrence

Give one instance its own title, location, and times (**Edited occurrences**). If that date is outside the pattern, Calendar also adds it as an Additional Date, then customizes it. The series title and location stay unchanged.

```
Can you add an occurrence for Sept 24 at 6pm - 10pm that is special because it's a Birthday Party for Jahid at Le Timme Horton
```

```
Add a special occurrence on October 24 from 6pm to 10pm titled "Birthday Party for Jahid" at "Tim Hortons"
```

```
On Sept 24 make it a Birthday Party at Le Timme Horton from 6pm to 10pm
```

```
Customize next Monday: rename to "Town Hall", location "Main Hall", 2pm–4pm
```

### Combined updates

Several changes in one prompt. Fields you do not mention stay as they were.

```
Move to next Tuesday at 3pm and make it weekly for 10 times
```

```
Rename to "Standup", location "Room A", every Monday and Thursday at 9am for 20 times
```

```
Make it weekly every Friday at 4pm, and add an additional date on Oct 24
```

```
Exclude next Monday and also add an additional date on Oct 31
```

```
Change description to "Client review" and move to tomorrow at 2pm
```

## Tips

- Prefer short, specific prompts for updates (“exclude next Monday”) over rewriting the whole event.
- Name the calendar in create prompts when you manage several calendars.
- **Additional Dates** = extra dates that inherit series details. **Edited occurrences** = one instance with its own title, location, or times.
- Review the draft after Generate / Apply before saving.
- Check credit balance and purchase bundles under **Calendar → Settings → SolspaceAI**.
